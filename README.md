# Land Acquisition AI

## Predictive Analytics System for Early Detection of Land Acquisition Delays

### 📌 About the Project
Land Acquisition AI is a web-based predictive analytics system designed to identify the risk of delays in land acquisition processes at an early stage.

The system analyzes important factors such as land area, document completion, and approval status to estimate the risk of delay.

### 🎯 Objective
The main objective is to provide an early warning about possible land acquisition delays so that responsible teams can take corrective action at the right time.

### ⚙️ How It Works
1. Enter the Land Area in acres.
2. Enter the percentage of Documents Completed.
3. Enter the Approval Status percentage.
4. Click the **Predict Delay** button.
5. The system displays the estimated delay risk.

### 💡 Key Features
- Simple and user-friendly interface
- Early identification of delay risk
- Percentage-based input analysis
- Instant risk prediction
- Web-based system accessible through a browser

### 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

### 📊 Output
The system provides a risk indication such as:
- Low Risk of Delay
- Medium Risk of Delay
- High Risk of Delay
